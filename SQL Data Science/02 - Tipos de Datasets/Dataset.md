# Dataset
Creado: 2022-04-16 22:07
Tags: #sql, #data-science, #dataset
Topic: [[Tipos de Datasets]] 

----

Un dataset (alfanumérico) es una colección de elementos de datos. Un **elemento** es usualmente llamado una **fila** o **tupla** (en el lenguaje de la base de datos); un **registro** (en el lenguaje general de Ciencia de la Computación); una **observación** (en el lenguaje de los estadísticos) o una **entidad**, **instancia**, o un **punto** (de dato) en otros contextos.
