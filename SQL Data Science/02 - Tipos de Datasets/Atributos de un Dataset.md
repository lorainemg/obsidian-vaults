# Atributos de un Dataset
Creado: 2022-04-16 22:14
Tags: #sql, #data-science, #dataset
Topic: [[Tipos de Datasets]]

----

Los atributos que componen un registro (una fila) de datos son llamados **schema** (**esquema**) del registro.

Los atributos de un dataset pueden ser **simples**, en cuyo caso el valor de un atributo puede ser un número o una etiqueta. Si tiene una estructura compleja, con partes en las que cada una tiene un valor, dicho atributo es llamado **complejo**
