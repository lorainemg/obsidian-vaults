# Cohesión de un Cluster
Creado: 2022-06-26 11:06
Tags: #sql, #data-science, #unsupervised, #cluster-cohesion
Topic: [[Enfoques no Supervisados]]

----

La cohesión de un cluster puede ser medido de varias formas; las típicas incluyen tomando la media de todas las distancias entre los pares de puntos en el cluster (a veces, el mínimo o el máximo es usado en vez del promedio)
