# Tratar con Bases de Datos
Creado: 2022-04-21 23:08
Tags: #sql, #data-science, #database, #code, #postgres, #mysql
Topic: [[Tablas de Bases de Datos]]

----

Los comandos principales de SQL para tratar con bases de datos son:
- Crear una base de datos: 
	```sql
	CREATE DATABASE {database-name}` o `CREATE SCHEMA {database-name}
	```
- Conectarse a una base de datos: 
	- En Postgres: 
	```postgres
	connect {database-name}
	```
	- En MySQL:
	```mysql
	use {database_name}
	```
