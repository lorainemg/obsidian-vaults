# Tabla de Datos Adecuada
Creado: 2022-04-21 23:59
Tags: #sql, #data-science, #database ,
Topic: [[Tablas de Bases de Datos]]

----
Una tabla de datos adecuada debe tener las siguientes características:
- Todos los valores deben estar en las celdas de datos, nunca en el esquema.
- Todos los atributos están en el esquema, nunca en los datos.
- Cada fila corresponde a un registro de datos (observación, en estadística) y cada columna a un atributo (variable, en estadística).
