# Objetivos Principales de EDA
Creado: 2022-05-15 23:26
Tags: #sql, #data-science, #eda 
Topic: [[EDA]]

----

Los principales objetivos de aplicar EDA son:
- Determinar qué tipo de dataset es (estructurado, semiestructurado, desestructurado). Si no es desestructurado, que tipo de esquema tiene.
- Determinar, para cada atributo, el tipo de dominio que representa (categórico/nominal, ordinal o numérico)
- Determinar cómo son los valores de datos en los dominios: cuál es un valor típico, cuál es el intervalo de valores, etc.
