# Eliminar y Actualizar Datos Existentes
Creado: 2022-04-23 23:28
Tags: #sql, #data-science, #code, #sql, #postgres  
Topic: [[Cargar y Descargar Datos de una BD]]

----

- Para eliminar datos existentes se usaría el siguiente comando:
```sql
DELETE FROM table-name WHERE condition
```
- Para actualizar datos existentes se usaría el siguiente comando:
```sql
UPDATE table-name SET attribute = value WHERE condition
```
