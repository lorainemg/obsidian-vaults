- Z-score relates the number of standard deviations away from the mean.
- Example:
$$X_{std} = \dfrac{X - \mu}{\sigma}$$
$$X_{std} \sim N(0, \sigma)$$

If your data is a normal distribution, the a standarization is a good place to start.

But I encourage you to try both standardization and normalization and compare the results
