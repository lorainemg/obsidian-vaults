### Kinds of Data Problems:
- Slow: Drift
	- Data Problems:
		- Trend and seasonability
		- Distribution of features changes
		- Relative importance of feature changes
	- World Changes:
		- Styles changes
		- Scope and processes change
		- Competitors change
		- Business expands to other geos
- Fast
	- Data Collection Problem:
		- Bad sensor/camera
		- Bad log data
		- Moved or disabled sensors/cameras
	- Systems Problem
		- Bad Software Update
		- Loss of network connectivity
		- System down
		- Bad credentials
