## POC and Production phases:
- **POC (Proof-of-concept):**
	- Goal is to decide if the application is workable and worth deploying.
	- Focus on getting the prototype to work!
	- It's ok if data pre-processing is manual. But take extensive notes/comments.
- **Production phase:**
	- After project is established, use more sophisticated tools to make sure the data pipeline is replicable.
