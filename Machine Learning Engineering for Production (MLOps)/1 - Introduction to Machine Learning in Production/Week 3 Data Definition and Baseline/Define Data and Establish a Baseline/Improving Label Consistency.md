## Actions to Improve Label Consistency:
- Have multiple labelers label same example.
- When there is disagreement, have MLE, subject matter expert (SME) and/or labelers discuss definition of *y* to reach agreement.
- If labelers believe that *x* doesn't contain enough information, consider changing *x*.
- Iterate until is hard to significantly increase agreement.

## Examples:
- Standarize Labels
- Merge Classes
- Add a Borderline class (unintelligible, non-sure)
