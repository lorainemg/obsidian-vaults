One of the key challenges in deploying a machine learning model are the software engineering issues, that includes  checklists of questions, like:
- Realtime or Batch
- Cloud vs. Edge/Browser
- Compute resources (CPU/GPU/memory)
- Latency, throughput (QPS)
- Logging
- Security and privacy.
