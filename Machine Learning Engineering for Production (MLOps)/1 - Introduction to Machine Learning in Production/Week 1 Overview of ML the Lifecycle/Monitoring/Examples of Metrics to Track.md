----

Some examples of metrics to track in the monitoring dashboard are:
- Software metrics:
	- Memory, compute, latency, throughput, server load.
- Input metrics:
	- Avg input length
	- Avg input volume
	- Num missing value
	- Avg image brightness
- Output metrics:
	- number of times returns " " (null)
	- number of times users redoes search
	- number of times switches to typing
	- CTR
