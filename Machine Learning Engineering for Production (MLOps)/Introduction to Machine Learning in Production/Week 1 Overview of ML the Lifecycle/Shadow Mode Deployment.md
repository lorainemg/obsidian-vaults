# Shadow Mode Deployment
Creado: 2022-10-22 16:27
Tags: #mlops #ml-project-lifecycle #deployment-stage #deploy-patterns #shadow-mode
Topic: [[Week 1 Overview of ML the Lifecycle]] 

----

The purpose of a shadow mode deployment is that allows you to gather data of how the learning algorithm is performing and how that compares to the human judgment.

In this mode, ML system and the human runs in parallel, making decisions, letting you verify how the learning algorithm is performing.

ML system's output not used for any decisions during this phase.
