# The ML project Lifecycle
Creado: 2022-10-22 15:47
Tags: #mlops #ml-project-lifecycle
Topic: [[Week 1 Overview of ML the Lifecycle]]

----

The ML project lifecycle has the following stages:
1. Scoping
	1. Define project
2. Data
	1. Define data and establish baseline
	2. Label and organize data
3. Modeling
	1. Select and train model
	2. Perform error analysis
4. Deployment
	1. Deploy in production
	2. Monitor & maintain system
