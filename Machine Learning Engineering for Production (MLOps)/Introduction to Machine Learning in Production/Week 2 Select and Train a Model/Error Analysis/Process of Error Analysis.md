Error analysis is an itereative process, where the main tasks are:
- Examine/tag examples.
- Propose tags.

This can be done through visual inspection of:
- Specific class labels (scratch, dent, etc...)
- Image properties (blurry, dark background, light background, reflection...)
- Other meta-data: phone model, factory
