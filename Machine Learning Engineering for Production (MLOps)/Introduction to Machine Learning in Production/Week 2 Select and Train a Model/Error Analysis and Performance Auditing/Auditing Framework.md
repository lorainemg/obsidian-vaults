An Auditing Framework is used to check for accuracy, fariness/bias, and other problems:
1. Brainstorm the ways the system might go wrong.
	- Performance on subsets of data (e.g. ethnicity, gender).
	- How common are certain errors (e.g. FP, FN).
	- Performance on rare classes.
2. Establish metrics to assess performance against these issues on appropiate slices of data.
3. Get business/product owner buy-in.
